Slovak translation of the Breakdance interface (editor and admin pages).

== Description ==

Adds Slovak translations to the Breakdance page builder.

- Translations apply only to users whose profile language is Slovencina (sk_SK). Other users see no change.
- Editor texts use the existing `breakdance_i18n_json` filter of Breakdance (wp.i18n).
- PHP texts (admin pages and editor texts generated by PHP) use the `gettext` filters for text domains starting with `breakdance`.
- Translations already provided by Breakdance are never overwritten; this plugin only fills the gaps.
- No Breakdance files are modified. No settings page: activate the plugin to enable the translation, deactivate it to restore the original texts.
- Texts that Breakdance does not pass through gettext (hardcoded strings), site content and the WordPress admin are not translated.

Tested with Breakdance 2.8.3. The `breakdance_i18n_json` filter is not documented as public API, so re-test after Breakdance updates.

== Installation ==

1. Upload the folder `breakdance-slovak-ui` to `wp-content/plugins/` (or install the ZIP).
2. Activate the plugin in WP Admin -> Plugins.
3. In Users -> Profile set Language to Slovencina.
4. Open the Breakdance editor or the Breakdance admin pages.

== Translation workflow (development) ==

All translations live in one file: `Translations/breakdance-sk_SK.json` (next to the plugin folder, not shipped in the ZIP).

- Edit only the `sk` and `status` fields of its entries (see `meta` in that file for the rules).
- `node "Build Scripts/validate-translations.mjs"` checks placeholders, HTML, plurals and protected terms (`--areas` shows progress per area).
- `node "Build Scripts/build-translations.mjs"` validates and generates `languages/js/*.json` (editor) and `languages/php/*.json` (PHP) in the plugin.
- `node "Build Scripts/sync-pot.mjs" --write` adds new texts from updated Breakdance POT files (new entries get status `todo`; existing translations are never changed).

== Release build ==

Run `build-release.ps1` from the parent project folder (PowerShell 7 and Node.js required). It validates and builds the translations first. The first release uses the version currently in the plugin; every following release increments the minor version. The script updates version metadata and this changelog, then creates and validates a ZIP under `Releases/` with `breakdance-slovak-ui` as its root folder.
